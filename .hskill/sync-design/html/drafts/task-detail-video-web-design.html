三种模式共享同一套 header 结构（返回箭头 + 标题 + 主题选择 ✦ + 新增「内嵌 / 右栏」开关 + ModeSwitcher + 甘特图入口 ▦ + ⌘K），仅 data-mode 驱动的内容区布局不同 — 模式A 是视频任务默认态（左 55% 播放器+笔记，右 45% 总结/文章正文）；模式F 剧场态把播放器提到顶部满宽展示，正文与笔记退居下方一行； 模式B 阅读优先态把正文列放大为主区域，播放器与转录字幕收进右侧 320px 固定侧栏。三态复用同一份播放器/笔记/字幕视觉语言，保持组件感一致。

模式A + 内嵌：左栏视频下方的评论列表不变（按时间看）；右侧正文同时出现内嵌卡片（按正文看）——同一条评论在两处各出现一次，这是有意的，悬停任一处另一处同步高亮。 模式A 本来就没有右侧笔记栏，所以切到「右栏」视图时正文里没有卡片、没有未定位区，与第 1 期一致。 卡片头部在有视频时间点时显示 @ 12:34（mono、accent 色），位于摘录之后、相对时间之前。

总结 / 文章 tab：每条新评论记录它所在的 tab（doc 字段）。另一个 tab 的评论不在当前正文里定位，进当前 tab 的「未定位评论」区——在总结 tab 写的「从 Query/Key/Value 的矩阵变换出发」那条，切到文章 tab 后出现在文首未定位区里，头部仍带原锚点摘录和时间点。 没有 doc 字段的旧评论（如「位置编码」那条）仍在当前 tab 尝试定位：两个 tab 都有这段文字，所以两边都内嵌显示；定位不到时才进未定位区。切 tab 会清掉正在写的草稿。

模式B + 右栏：与第 1 期一致——正文右侧有 260px 笔记栏（.notes-col），无锚点评论在顶部正常排列，有锚点的卡片按锚点高度对齐；切回「内嵌」时笔记栏不渲染，正文列占满这块宽度，卡片进正文。 草稿卡片：点评论后在锚点所在段落的槽位里出现编辑中的卡片（绿色描边），视频在播时头部带当前时间点，⌘↵ 保存 · Esc 放弃。
